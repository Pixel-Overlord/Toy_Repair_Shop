# 🧸 Toy Repair Shop

A cozy, casual 2D mobile game where players restore broken toys using interactive repair tools. Each toy goes through multiple repair stages, rewarding players with satisfying animations, visual effects, and collectibles.

> ⚠️ This project is currently in active development.

---

## 📌 Current Progress

### ✅ Art & Asset Pipeline
- Custom cartoon art style established
- Power-of-two sprite sheets for optimized mobile rendering
- Consistent asset naming convention
- Sprite atlases for UI, tools, toys, and effects
- Transparent game-ready sprites

### ✅ Environments
- Main Menu background
- Workshop background
- Interactive workshop layout
- Optimized static background with removable interactive objects

### ✅ UI Assets
- Main menu
- Progress bar
- Buttons
- Panels
- Coin icon
- Effects sprites

### ✅ Toys
Implemented repair sequences for multiple toys.

Current repair workflow:

```
Broken
   ↓
Repair Step 1
   ↓
Repair Step 2
   ↓
Fully Repaired
```

Available toys include:

- Teddy Bear
- Robot
- Toy Train
- Toy Car
- Airplane
- Bunny
- Rocket
- Drum
- Boat
- Additional toy variations
